## 6. ระบบรันโค้ด (Runner)
- Pyodide รันใน `src/workers/pyodide.worker.js` และเริ่มโหลดเบื้องหลังหลังจากหน้าแรกแสดงผลแล้ว
- การรันแต่ละครั้งใช้ namespace ใหม่ ตัวแปรจากการรันครั้งก่อนจึงไม่ติดมา
- **Message protocol:**

| ทิศทาง | type | ข้อมูล |
|---|---|---|
| หน้าเว็บ → worker | `init` | — |
| หน้าเว็บ → worker | `run` | `id, mode ('python' หรือ 'sql'), code, stdin, packages, datasets, tests?` |
| worker → หน้าเว็บ | `status` | `state, message` (ข้อความไทย เช่น "กำลังเตรียม pandas") |
| worker → หน้าเว็บ | `stdout` / `stderr` | `id, text` |
| worker → หน้าเว็บ | `image` | `id, dataUrl` (PNG) |
| worker → หน้าเว็บ | `table` | `id, columns, rows, totalRows` |
| worker → หน้าเว็บ | `result` | `id, repr` (ค่าของ expression บรรทัดสุดท้าย) |
| worker → หน้าเว็บ | `done` | `id, ok, error?: {type, message, line, traceback}, testResult?` |

- **แสดงค่าบรรทัดสุดท้าย (แบบ Jupyter):** ถ้าบรรทัดสุดท้ายเป็น expression ให้แสดงค่าของมัน ถ้าเป็น DataFrame หรือ Series ให้ส่งเป็น `table` (แสดงสูงสุด 50 แถว) ส่วนค่าชนิดอื่นให้ส่งเป็น `repr`
- **input():** มีช่อง "ข้อมูลสำหรับ input()" ซึ่งแสดงเฉพาะเมื่อโค้ดมีคำว่า `input(` แต่ละบรรทัดในช่องจะถูกใช้ตามลำดับ ถ้าข้อมูลหมด ให้แจ้งเป็นภาษาไทยว่าต้องกรอกเพิ่ม
- **หยุดโค้ด:** ตั้งเวลาหยุดอัตโนมัติไว้ที่ 10 วินาที โดยไม่นับเวลาโหลด package และมีปุ่ม "หยุด" ด้วย เมื่อหยุดโค้ด ให้ terminate worker แล้วสร้าง worker ใหม่ พร้อมแจ้งผู้เรียนว่าโค้ดอาจวนลูปไม่รู้จบ
- **จำกัด output:** ถ้า output เกิน 10,000 บรรทัดหรือ 1 MB ให้ตัดส่วนที่เกินและแจ้งผู้เรียน
- **Package:** ใช้ `loadPackagesFromImports` ร่วมกับรายการ `packages` ใน frontmatter ของบท และแสดงสถานะการโหลดเป็นภาษาไทย
- **ไฟล์ข้อมูล:** ดาวน์โหลดไฟล์ตามรายการ `datasets` ของบทจาก `public/datasets/` แล้วเขียนลงที่ `/home/pyodide/data/` ผู้เรียนจึงเรียกใช้ได้ด้วย `pd.read_csv("data/sales.csv")`
- **กราฟ:** ใช้ backend `Agg` และโหลดฟอนต์ไทย TTF จาก `public/fonts/` ลงทะเบียนกับ `font_manager` แล้วตั้งเป็นฟอนต์เริ่มต้น เพื่อให้ภาษาไทยในกราฟไม่กลายเป็นสี่เหลี่ยม หลังรันเสร็จให้แปลงทุก figure เป็น PNG แล้วเรียก `plt.close('all')`
- **โหมด SQL:** สร้าง SQLite `/home/pyodide/data/baan_kafae.db` จาก CSV ชุดที่สะอาดแล้วด้วย `sqlite3` + `csv` (ไม่ใช้ pandas) ถ้ามีหลายคำสั่ง ให้แสดงผลของ SELECT สุดท้าย
- **ตรวจโค้ดก่อนรัน (ฝั่ง JavaScript):** ตรวจหาเครื่องหมายคำพูดแบบโค้ง `“ ” ‘ ’` ตัวอักษรเต็มความกว้าง เช่น `（ ）：，` และ non-breaking space ถ้าพบให้เตือนพร้อมเลขบรรทัด แต่ยังให้รันได้
- **Error:** ตัดบรรทัด traceback ที่มาจากภายใน Pyodide ออก เลขบรรทัดต้องตรงกับโค้ดของผู้เรียน และแสดงคำอธิบายภาษาไทยจาก `content/errors.yaml` ใต้ข้อความ error

## 8. แบบฝึกหัด
| type | ใช้กับ | วิธีตรวจ |
|---|---|---|
| `output` | โจทย์ที่ให้ print | เทียบ output หลังตัดช่องว่างท้ายบรรทัดและบรรทัดว่างท้ายสุดออก โดยตั้ง `outputMatch: exact` หรือ `contains` ได้ |
| `assert` | ตัวแปร ฟังก์ชัน DataFrame และกราฟ | รันโค้ดผู้เรียน แล้วรัน `tests` ต่อใน namespace เดียวกัน โดยใช้ตัวแปร `_output` ดู output ได้ ถ้ามี assert ที่ไม่ผ่าน ให้แสดงข้อความของ assert แรกที่ไม่ผ่าน |
| `sql` | SQL | เทียบผลลัพธ์ของคำตอบผู้เรียนกับเฉลยเฉพาะค่า ไม่เทียบชื่อคอลัมน์ ลำดับแถวมีผลเฉพาะเมื่อตั้ง `ordered: true` |
| `quiz` | ส่วนที่ 0 และแนวคิดต่าง ๆ | ปรนัย แสดงคำอธิบายหลังตอบ |
| `checklist` | โปรเจกต์และงานติดตั้งโปรแกรม | ผู้เรียนติ๊กตรวจงานตัวเอง |

- คำใบ้เปิดได้ทีละขั้น ปุ่ม "ดูเฉลย" จะแสดงเมื่อผู้เรียนส่งคำตอบผิด 3 ครั้ง หรือเปิดคำใบ้ครบทุกขั้นแล้ว และต้องกดยืนยันก่อนจึงเห็นเฉลย
- บทเรียนนับว่าเรียนจบเมื่อผ่านแบบฝึกหัดครบทุกข้อ ถ้าบทนั้นไม่มีแบบฝึกหัด ให้มีปุ่ม "เรียนจบบทนี้"
- เมื่อผ่านแบบฝึกหัด ให้แสดง animation แสดงความยินดีเล็ก ๆ ที่ไม่รบกวนการเรียน

- **Export/Import:** Export เป็นไฟล์ JSON `{app, schemaVersion, exportedAt, data}` เมื่อ Import ให้ตรวจไฟล์ด้วย zod และให้ผู้เรียนยืนยันก่อนเขียนทับข้อมูลเดิม
- **ดาวน์โหลดโค้ด:** ดาวน์โหลดโค้ดใน editor เป็น `.py` หรือ `.ipynb` (nbformat 4 มี markdown cell สำหรับชื่อบท และ code cell สำหรับโค้ด)

## 10. Offline และ PWA
- **Manifest:** name "ความรู้มี (ไม่) จำกัด", short_name "ความรู้มี", lang `th`, display `standalone`, theme_color `#A8DDB5`, background_color `#F3FAF5` และมีไอคอนขนาด 192, 512 และแบบ maskable
- **Precache:** app shell, เนื้อหาที่ build แล้ว, ฟอนต์, ไฟล์ข้อมูล และฟอนต์ไทย TTF
- **Runtime cache:** ไฟล์ Pyodide จาก CDN ใช้ CacheFirst
- **ดาวน์โหลดสำหรับใช้ offline:** ปุ่มในหน้าตั้งค่าจะโหลด Pyodide, pandas และ matplotlib ล่วงหน้าพร้อมแสดงสถานะ ตอนเปิดแอปครั้งแรกให้มีแบนเนอร์แนะนำปุ่มนี้
- **อัปเดต:** ใช้ `registerType: 'prompt'` เมื่อมีเวอร์ชันใหม่ ให้แสดง toast "มีเนื้อหาใหม่ กดเพื่ออัปเดต"
- **สถานะ offline:** แสดงเมื่อเครื่องไม่ได้ต่อเน็ต ถ้ายังไม่ได้ cache Pyodide ให้บอกผู้เรียนว่าต้องต่อเน็ตก่อน

|---|---|---|
| `branches.csv` | 5 | branch_id, branch_name, district, open_date, seats |
| `products.csv` | ~20 | product_id, product_name, category (กาแฟ/ชา/นม/ขนม), price, cost |
| `customers.csv` | ~800 | customer_id, member_tier (Silver/Gold/Platinum), age_group, join_date |
| `sales.csv` | ~15,000 (ปี 2024) | order_id, order_datetime, branch_id, product_id, quantity, unit_price, discount, payment_method (เงินสด/QR/บัตร), customer_id (เว้นว่างได้) |
| `sales_dirty.csv` | ~3,000 (3 เดือน) | คอลัมน์เดียวกับ sales แต่ใส่ปัญหาไว้โดยตั้งใจ |

- **รูปแบบที่ข้อมูลต้องมี** (ใช้หา insight ในบท storytelling): ยอดขายวันหยุดสูงกว่าวันธรรมดา ช่วงเช้ามียอดขายสูงสุด เครื่องดื่มเย็นขายดีในเดือนเมษายน และยอดขายแต่ละสาขาต่างกันชัดเจน
- **ปัญหาที่ใส่ใน `sales_dirty.csv`:** quantity หายไป ~3%, แถวซ้ำ ~1%, รูปแบบวันที่ปนกัน (`2024-01-05`, `05/01/2024`, `5 ม.ค. 2567`), ชื่อสาขาเขียนไม่ตรงกัน (มีช่องว่างหน้าหลัง หรือมี/ไม่มีคำว่า "สาขา"), unit_price เป็นข้อความที่มี "฿" และ "," และ quantity ผิดปกติ เช่น 999
- สคริปต์สร้าง `content/datasets/README.md` อัตโนมัติ โดยระบุคอลัมน์ จำนวนแถว จำนวนปัญหาแต่ละประเภท และตัวเลขสำคัญ เช่น ยอดขายรวมรายสาขารายเดือน เพื่อให้บทเรียนอ้างอิงตัวเลขได้ถูกต้อง
- ห้ามมีชื่อคนจริงในข้อมูล

# finish-task

## ขั้นที่ 1 ตรวจอัตโนมัติ
รัน `npm run lint`, `npm test` และ `npm run build` ถ้ามีการแก้ไฟล์ใน `content/` ให้รัน `npm run content:check` ด้วย
ถ้าคำสั่งใดไม่ผ่าน ให้แก้จนผ่าน ห้ามปิด test, ปิด lint rule หรือข้าม test เพื่อให้ผ่าน

## ขั้นที่ 2 ตรวจงานตัวเองจาก git diff
- มีไฟล์ที่แก้นอกขอบเขตของ task ไหม
- มีข้อความภาษาไทยที่เขียนไว้ในคอมโพเนนต์โดยตรงไหม
- มีสีหรือฟอนต์ที่ไม่ได้ใช้ token ไหม
- มี `console.log` หรือโค้ดทดลองค้างอยู่ไหม
- เพิ่ม dependency ใหม่ไหม ถ้าเพิ่ม เจ้าของอนุญาตแล้วหรือยัง
- ทำครบทุกข้อใน "เกณฑ์ผ่าน" แล้วหรือยัง

## ขั้นที่ 3 อัปเดตเอกสาร
- ใน `docs/PLAN.md` เพิ่มบรรทัด `หมายเหตุ:` ใต้ task ถ้ามีเรื่องที่ต้องบันทึก (ยังไม่ต้องติ๊ก [x])
- ถ้ามีการตัดสินใจใหม่ ให้บันทึกใน `docs/DECISIONS.md`

## ขั้นที่ 4 ส่งสรุปให้เจ้าของตามรูปแบบนี้
## สรุปงาน <รหัส task> <ชื่อ task>
**สิ่งที่ทำ:** (2–4 ประโยคด้วยภาษาง่าย ๆ)
**ไฟล์ที่สร้างหรือแก้:** (รายการ path)
**วิธีตรวจด้วยตัวเอง:**
1. เปิด terminal แล้วพิมพ์ ...
2. เปิดเบราว์เซอร์ไปที่ ...
3. คลิก ... แล้วควรเห็น ...
**ผลการตรวจอัตโนมัติ:** lint / test (จำนวน test) / build / content:check
**เกณฑ์ผ่าน:** (ไล่ทีละข้อว่าผ่านหรือไม่ผ่าน)
**ข้อจำกัดหรือสิ่งที่ยังไม่ได้ทำ:**
**ข้อสังเกต (นอกขอบเขต):**
**คำถามถึงเจ้าของ:**

ปิดท้ายด้วยข้อความ: "ถ้าตรวจแล้วเรียบร้อย พิมพ์ 'ผ่าน' หรือบอกจุดที่ต้องแก้ได้เลย"

## ขั้นที่ 5 เมื่อเจ้าของพิมพ์ "ผ่าน"
1. ติ๊ก [x] ที่ task ใน `docs/PLAN.md`
2. `git add -A` แล้ว `git commit -m "<รหัส task>: <สรุปภาษาไทยสั้น ๆ>"`
3. ถ้ามี remote แล้ว ให้ `git push`
4. หยุดทำงาน ห้ามเริ่ม task ถัดไปเอง

# review-lesson

บทบาท: ผู้ตรวจที่เข้มงวด ไม่ใช่ผู้เขียน **ห้ามแก้ไฟล์ ให้รายงานผลอย่างเดียว**

## ขั้นตอน
1. อ่าน `content/AGENTS.md`, `content/glossary.yaml`, `content/datasets/README.md` และ `introduces` ของทุกบทก่อนหน้า
2. รัน `npm run content:check`
3. ตรวจบทที่ได้รับมอบหมายตาม checklist ทีละบท

## Checklist
**ความถูกต้องทางเทคนิค**
- คำอธิบายถูกต้องตามการทำงานจริงของ Python, pandas หรือ SQL และไม่ทำให้ง่ายจนเนื้อหาผิด
- ผลลัพธ์ที่บทเรียนบอก ตรงกับผลที่โค้ดรันได้จริง
- test ไม่หลวมเกินไป คือคำตอบผิดต้องไม่ผ่าน และไม่เข้มเกินไป คือคำตอบที่ถูกแต่เขียนต่างวิธีต้องผ่าน
- ไม่มีการใช้สิ่งที่ผู้เรียนยังไม่ได้เรียน

**การสอน**
- objectives ชัดเจนและวัดผลได้ และหัวข้อ "ทำไมต้องรู้" เชื่อมกับงานจริง
- มีแนวคิดใหม่ไม่เกิน 3 อย่าง ความยาวเหมาะกับเวลา 10–15 นาที และคำใบ้ไล่ระดับจากกว้างไปเฉพาะ

**ภาษา**
- ศัพท์ตรงกับ glossary สะกดถูกต้อง น้ำเสียงตรงตามกฎ และไม่มีคำต้องห้าม

**อื่น ๆ**
- มีกล่อง `:::mac` ในจุดที่ Windows กับ Mac ต่างกัน
- ตัวเลขตรงกับข้อมูลสมมติ และไม่มีข้อมูลบุคคลจริงหรือเนื้อหาอ่อนไหว
